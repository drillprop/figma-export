# figma-export

Export Figma nodes/components to local repo files, via a Figma plugin + a local Hono server. See `README.md` for setup and usage.

## Agent skills

### Issue tracker

Issues live as GitHub issues on `drillprop/figma-export` (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical roles — `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
